# staffix-http-client-test-kit

This artifact has no hand-written main source and no javadoc.

It is a test kit: shared contract tests and helpers, living under `src/test/java`, published so that an
implementation outside this repository can be run against the same contract. There is nothing in
`src/main/java` to document or to package as sources.

See https://github.com/lolaf-org/staffix
