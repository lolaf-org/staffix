staffix-components-catalogue holds no code: its jar is data, the metadata of every staffix component.

META-INF/staffix/catalogue.v1.json indexes the components; each entry names its files under META-INF/staffix/,
a JSON Schema of the settings (components/) and the Spring Boot properties (spring/).

See https://github.com/lolaf-org/staffix for the sources of each component.
